# Overview

Backyard Flyer is an interactive learning environment for quadcopter control fundamentals. The goal is to build intuition for how a real flight controller works — not by reading about it, but by running the code, breaking it, and watching what happens.

The course walks through increasingly realistic simulations, starting from a single incrementing counter and working up to a quad copter with attitude control. Each simulation runs live in the browser: you can read the source, edit any block of the flight controller or physics model, stage your changes, and restart to see the effect immediately.

Use the table of contents on the left to navigate. Simulation pages have three tabs — **Chapter** for the explanation, **Source** to edit the model blocks, and **Visualisation** for the 3D scene, live charts, and playback scrubber.
