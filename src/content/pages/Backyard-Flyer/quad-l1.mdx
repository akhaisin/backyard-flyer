# Quad Demo — full mission sequence

**Quad Demo** is a quadcopter simulation that executes a complete autonomous mission: arm, take off, navigate a rectangular route through four waypoints, return home, land, and disarm.

The simulation runs at **50 ms per tick** (20 Hz). Four blocks execute in order each tick:

```
mission → fc → hw → world
```

- **`mission`** — state machine that sequences all flight phases
- **`fc`** — cascaded flight controller: position loop → attitude loop → motor mixing
- **`hw`** — four independent motors with spool-up inertia
- **`world`** — 6 DOF rigid-body physics: forces and torques → position and orientation

---

## Motor layout

The quad uses an **X configuration** with four fixed-direction motors, all pointing straight up in the body frame. Differential thrust between motors produces roll, pitch, and yaw moments.

```
   forward (+X)
       |
  M0 · · M1        M0 front-left  (CCW)
    \   /           M1 front-right (CW)
    /   \           M2 rear-right  (CCW)
  M3 · · M2        M3 rear-left   (CW)
       |
     right (+Z)
```

| Axis | Torque equation |
|------|----------------|
| Roll  (X) | `ARM · (M0 − M1 − M2 + M3)` |
| Pitch (Z) | `ARM · (M0 + M1 − M2 − M3)` |
| Yaw   (Y) | `K_DRAG · (−M0 + M1 − M2 + M3)` |

---

## Flight controller — cascaded loops

The FC runs two loops in series every tick.

**Outer loop — position PID → attitude setpoint**

Position error and velocity feed a PID law that produces a desired acceleration. `KI_POS = 0` because this model has no persistent horizontal disturbances — gravity is handled as explicit feedforward, and `world.ts` models no wind or drag. PD alone converges to zero position error in a disturbance-free environment. The integral state is tracked in the simulation state anyway, so adding wind or drag later requires only a `KI_POS` value change.

The desired acceleration is converted into desired roll and pitch angles (small-angle approximation), clamped to ±17° to keep the motors out of saturation. Total thrust is scaled up to compensate for the reduced vertical component when the drone is tilted.

**Inner loop — attitude PID → torques → motor mix**

Attitude error and angular velocity feed a second PID law that produces desired roll, pitch, and yaw torques. `KI_ATT = 0` because the motors are perfectly symmetric with no persistent torque bias. PD drives attitude error to zero without integral action. The integral state is wired through for the same reason as above — tune `KI_ATT` when motor imbalance or aerodynamic asymmetry is modelled.

The motor mixer then inverts the torque equations to compute the individual motor force required from each of the four motors, converts to 0–1 power fraction, and clamps.

```
position error → desired tilt angles (clamped ±17°)
                         ↓
attitude error → desired torques
                         ↓
              motor mix → M0, M1, M2, M3 (0–1)
```

> **Gain tuning and simulation timestep.** The attitude inner loop runs at the same 20 Hz as everything else. With I = 0.01 kg·m², the discrete stability limit for the derivative gain is `KD < 2·I/DT = 0.4`. Gains above that limit cause the angular velocity to flip sign every tick and diverge instantly — which looks like an uncontrolled pitch-down on the first waypoint leg.

## Mission phases

| Phase | Name | What happens |
|-------|------|--------------|
| 0 | ARMING | Motors spin up (1 s) |
| 1 | TAKEOFF | Climb to 5 m altitude |
| 2 | NAVIGATE | Fly through 4 rectangular waypoints |
| 3 | RTH | Return to home position at cruise altitude |
| 4 | LAND | Descend to ground |
| 5 | DISARMING | Motors spool down (1 s) |
| 6 | DONE | Simulation complete |

## Ground contact model

`world.ts` uses a simple ground-contact rule. Every tick where the quad is at or below `y = 0`:

- Vertical velocity is zeroed if downward (no bounce).
- Horizontal velocities **vx** and **vz** are multiplied by **0.7** — roughly 30 % lost per tick.

At 20 Hz that bleeds off nearly all lateral inertia in about half a second, standing in for ground friction without needing a full contact-dynamics model. Increase the factor toward 1.0 for an icy surface; drop it toward 0 for an instant stop.
