# Course structure

The course is a **work in progress**. The full curriculum will build up from a single counter to a full quadcopter with attitude control — but for now, four simulations are available to explore. Each one runs live in the browser; you can read, edit, and restart any block.

## Available now

- **[Inc — minimal simulation](#sim-demo/inc)** — one block, one number, one tick per second. The smallest possible model. Useful for verifying the editor + run loop before tackling anything physical.

- **[PID tutorial — control fundamentals](#sim-demo/pid-tutorial)** — a single 1D plant driven by a PID controller. Live sliders for target, gains (Kp, Ki, Kd), and plant parameters (mass, damping) let you build intuition for what each term does — start with pure P, add D to damp oscillation, add I to kill steady-state error.

- **[Floater — multi-block model with simulated hardware](#sim-demo/floater)** — a sphere chasing waypoints in 3D. Four blocks (`mission → fc → hw → world`) demonstrate how a controller, an actuator with inertia, and a physics integrator are layered. State is structured into sub-trees (`pos`, `vel`, `thrust.desired/actual`, `mission.target`).

- **[PD vs PID — two controllers, side by side](#sim-demo/floater-pid)** — two floaters fly mirrored waypoint paths. One uses a PD controller (proportional + damping), the other a full PID. Same hardware, same physics — only the control law differs. Includes a note on why *pure* P can't converge (think planetary orbits).

More models (attitude control, real-world disturbances, full quadcopter) will follow.
