# Quad W1b — pre-stage approach

**Quad W1b** is [Quad W1a](/Backyard-Flyer/quad-w1a) with one block swapped. It reuses the entire shared stack — `lifecycle`, `mission`, `navigator_w1`, `planner_wp`, `fc_acro`, `hw`, `world`, `wind`, `noise` — and only replaces the path planner:

| Block | W1a | W1b |
|-------|-----|-----|
| planner | `planner_w1a` — centerline carrot | `planner_w1b` — centerline carrot **+ pre-stage leg** |
| everything else | shared | identical |

The centerline carrot already flies the drone through the middle of each gate. W1b adds a **pre-stage waypoint** in front of each gate so the drone is settled on the approach axis *before* it commits — useful when the entry into a gate is oblique and would otherwise carry lateral momentum into the frame.

---

## Pre-stage waypoint

Each gate's route entry carries a `preStageDist`. The planner places a pre-stage point that far behind the gate along the inverse normal, and flies there first (a plain point-seeking carrot) before switching to the centerline carrot for the final run:

```
              preStage              gate
   drone ───────●───────────────────[  ]──► normal
                ↑
          preStageDist = 5 m  (back along −normal)
```

A `preGateDone` **latch** flips to 1 the first tick the drone comes within `PREGATE_THRESHOLD` (1.5 m) of the pre-stage point, and stays latched for the rest of the gate. Without the latch the target would oscillate — the drone passes the pre-gate, its distance grows again, and the target snaps backward. On a restart (missed gate) the latch resets so the pre-stage repeats.

`preStageDist ≤ 0` collapses the block back to exactly `planner_w1a`'s behaviour, so the same block serves a whole route of mixed gates.

## Mission state and restarts

## Edit the path planner

`planner_w1b` adds the pre-stage leg and `preGateDone` latch on top of W1a's centerline carrot and crossing detection. Try changing `PREGATE_THRESHOLD`, or set every gate's `preStageDist` to 0 (in the route, via `lifecycle`) to watch it degrade to W1a.
